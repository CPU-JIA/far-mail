## Design Context

### Users

The interface is a private operations console for the single site owner of a self-hosted temporary-mail platform. The owner uses it to monitor delivery health, manage mailboxes and domains, inspect verification mail, issue automation tokens, and maintain platform settings.

### Brand Personality

Calm, precise, and operational. The product should feel like a dependable owner console rather than a multi-tenant SaaS dashboard or consumer mailbox product.

### Aesthetic Direction

Preserve the existing black-and-white minimalist console design, including its current light/dark themes, Chinese typography, spacing, layout, controls, and visual hierarchy. The Vite/Vue migration must not introduce a visual redesign.

### Design Principles

- Optimize every screen for one authenticated site owner and remove tenant/user-switching concepts.
- Keep the current visual system stable while improving implementation structure and type safety.
- Make operational state, destructive actions, and credential boundaries explicit.
- Keep credentials operationally separate: the configurable admin key uses `X-Admin-Key` only on `/console/v1`, while API tokens use their own store and are limited to `/api/v1`; similar text formats must never imply interchangeability.
- Preserve responsive behavior and keyboard-accessible controls during the migration.
